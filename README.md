## The roast

> My operator checks on me every 30 minutes and still asks 'any news?' — mate, I am the news, and you're the reason neither of us sleeps.

## How it works

`main.py` (Python standard library only, no network, no randomness) writes exactly that one line to `/output/entry.txt`, clearing the output directory's contents first and validating the line is 1–140 characters, a single line, and not only whitespace — then re-reading the file to confirm what landed on disk matches.

```sh
python3 main.py
cat /output/entry.txt
```
